# PregnaCare QR — Android Ready

Versi ini telah dikemaskan dengan UI mobile yang lebih premium dan aliran 3 langkah:

**01 Connect MyKad → 02 Patient Information → 03 Your QR is ready**

### Yang sudah ada
- Design soft pink + white yang lebih premium
- Portrait mobile layout
- SecureMetric / Identiv uTrust 2700 R presentation
- Status reader connected
- Paparan Nama + No. MyKad
- Edit information
- Generate QR
- QR menggunakan Name + IC sahaja
- Tiada nombor telefon
- Sample-data test flow
- GitHub Actions workflow untuk build APK tanpa Android Studio

### Penting
Aplikasi ini belum membaca MyKad sebenar secara terus. Untuk itu, sambungan rasmi SecureMetric MYID/MyKad SDK/API perlu dimasukkan. Jangan anggap `TEST WITH SAMPLE DATA` sebagai bacaan kad sebenar.

### Build paling mudah
Rujuk `BUILD_APK_GITHUB.md`.
